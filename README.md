# Team ROBI

Website for **Team ROBI**, a research team at the [Biointelligence Lab](https://bi.snu.ac.kr), Seoul National University, advised by Prof. Byoung-Tak Zhang. We work on Embodied AI, Robot Perception, Vision-Language-Action (VLA) models, 3D Scene Understanding, Robot Learning, and Sim2Real Transfer.

See the site's `about`, `publications`, `awards`, and `people` pages for details.

## Development

This site is built with [al-folio](https://github.com/alshedivat/al-folio), a Jekyll theme for academic websites, in its pluginized v1.x form (a thin starter repo plus versioned `al_folio_core`/`al_*` gems). See [`AGENTS.md`](AGENTS.md) for the local dev command set, [`docs/BOUNDARIES.md`](docs/BOUNDARIES.md) for starter-vs-plugin ownership, and [`docs/PROJECT_PAGES.md`](docs/PROJECT_PAGES.md) for the paper project-page template. For general al-folio setup, customization, or troubleshooting topics not specific to this site, see the [upstream al-folio repository](https://github.com/alshedivat/al-folio) and its own `docs/`.
